使用提示
  • 背单词/语法卡片中：空格 翻面，1 不会，2 模糊，3 会，←/→ 上一张/下一张。
  • 「已掌握」的卡片在下次复习中权重降低；「学习中」会优先出现。
  • 本地推荐运行 npm start 或 python serve_with_progress.py；进度会保存到同目录的 lyricjlpt-progress.json。
  • AWS 上线后点击「云端设置」，填入 Lambda Function URL 和 sync token；未配置或网络失败时会回退到浏览器 localStorage。
